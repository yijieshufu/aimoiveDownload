## 项目目标

本项目已完成一个可运行的 Web 视频下载工具，核心目标是：

- 提供可视化页面输入视频链接并解析
- 支持抖音链接无水印下载
- 支持后端统一下载与文件回传

## 已完成能力

### 1) 后端 API 能力（FastAPI）

- `POST /api/extract`：解析视频信息和可下载格式
- `GET /api/download`：按 `format_id` 执行下载
- `GET /api/download/file`：回传本地下载文件
- `GET /api/thumbnail`：代理封面图请求，规避部分站点防盗链
- `POST /api/douyin/parse`：抖音专用解析，返回 `video_id` 与无水印地址

### 2) 抖音解析链路（免手工 cookies）

当前实现采用“双通道”策略：

1. 短链跳转提取 `video_id`
2. 优先调用 `iesdouyin` 公开接口获取视频信息
3. 若公开接口空返回，回退抓取公开分享页提取 `playwm`
4. `playwm` 替换为 `play` 获取无水印播放地址

并已处理：

- 分享文案中 URL 自动提取
- 标题/作者文本乱码修复
- 封面提取兜底与封面代理展示

### 3) 前端交互能力

- 单页输入链接并解析展示
- 展示标题、作者、时长、封面、格式卡片
- 一键触发下载与完成后文件获取
- 移除 cookies 上传入口，保持简化流程

### 4) 下载体验优化

- 抖音无水印链接支持直接下载
- 文件大小探测逻辑已加入（优先 `HEAD`，再 `Range`，再 `GET` 头兜底）
- 常见错误信息已转为可理解提示

## 当前限制与建议

- 不同时间段抖音风控策略会变化，公开接口存在波动
- 个别视频可能仍出现解析失败，建议保留多重兜底策略
- 后续可增加：
  - 可选“压缩下载”（如 480p）
  - 任务队列与下载历史
  - 更细粒度错误分类和重试机制
