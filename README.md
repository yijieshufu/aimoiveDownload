# Video Downloader - 极速视频下载工具

基于 yt-dlp 的 Web 视频下载器，具有高级付费质感的用户界面，支持多个平台的视频下载。

## 功能特点

- 🚀 **极速解析**：快速分析视频信息和可用格式
- 🎯 **全能兼容**：支持多个视频平台
- 💎 **无损画质**：提供多种画质选择
- 🎨 **高级界面**：具有付费质感的现代 SaaS 风格
- 📊 **实时进度**：可视化下载进度和速度

## 技术栈

- **前端**：HTML5, Tailwind CSS, JavaScript
- **后端**：Python, FastAPI
- **核心**：yt-dlp
- **部署**：轻量级容器化部署

## 环境要求

- Python 3.7+
- pip
- 互联网连接（用于下载依赖和视频）

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 启动后端服务

```bash
uvicorn backend.main:app --host 0.0.0.0 --port 8000
```

### 3. 访问前端页面

打开浏览器，访问 `http://localhost:8000/frontend/index.html`

## API 接口

### 1. 提取视频信息

- **URL**: `/api/extract`
- **方法**: POST
- **参数**: `{"url": "视频URL"}`
- **返回**: 视频信息和可用格式列表

### 2. 解析抖音无水印地址（新增）

- **URL**: `/api/douyin/parse`
- **方法**: POST
- **参数**: `{"url": "抖音分享链接或包含链接的文案"}`
- **返回**: `video_id`、标题、作者、`no_watermark_url`

### 3. 下载视频

- **URL**: `/api/download`
- **方法**: GET
- **参数**: `?url=视频URL&format_id=格式ID`
- **返回**: 下载结果信息

## 使用说明

1. 在输入框中粘贴视频 URL
2. 点击「开始解析」按钮
3. 等待解析完成，查看视频信息
4. 选择合适的画质和格式
5. 点击「下载」按钮开始下载
6. 查看下载进度和速度
7. 下载完成后点击「下载文件」按钮获取文件
